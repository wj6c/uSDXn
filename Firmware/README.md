# uSDXn V1 Firmware

The uSDXn V1 firmware is currently under development.

At this stage, uSDXn V1 does not include its own finalized firmware.

Users are free to experiment with existing uSDX-compatible firmware and other firmware developments available from the amateur radio community.

No specific firmware is currently recommended by the uSDXn project. Builders should select the firmware that best matches their hardware configuration and experimental needs.

The uSDXn project will continue testing and experimenting with existing firmware while developing and evaluating the requirements for a dedicated uSDXn V1 firmware.

When a dedicated uSDXn V1 firmware is ready, it will be published in this directory together with the appropriate documentation and attribution.

## Firmware Development

The future uSDXn V1 firmware will be developed with the uSDXn hardware architecture and its specific controller, display, encoder, PTT, CW, and RF control requirements in mind.

Until then, this directory serves as a placeholder for future uSDXn firmware development.
